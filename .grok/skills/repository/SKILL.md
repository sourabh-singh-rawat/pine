# Repository

Persistence only. Canonical: `platform-service` `features/workspaces/repositories`. Related: `service-feature`, `service`, `drizzle`, `outbox`.

## Layout

```text
services/<svc>/src/
  db/
    columns.ts
    tables/X.ts
    tables/index.ts
    schema.ts
    types.ts
  features/<feature>/repositories/
    IFooRepository.ts
    FooRepository.ts
    index.ts
```

`columns.ts`: `idColumn` + `auditColumns`. `tables/X.ts`: `pgTable` + relations + `$inferSelect`. `schema.ts` re-exports tables (+ `OutboxMessages` when used). `types.ts`: `Database`, `Transaction`, `DbClient`.

## Table

Export select/insert types from the table file. Re-export from `db/schema.ts` and `db/tables/index.ts`.

```ts
export const Workspaces = pgTable(
  "workspaces",
  {
    ...idColumn,
    tenantId: uuid("tenant_id").notNull().references(() => Tenants.id),
    name: varchar("name", { length: 255 }).notNull(),
    slug: varchar("slug", { length: 100 }).notNull(),
    ...auditColumns,
  },
  (table) => [unique().on(table.tenantId, table.slug)],
);

export type Workspace = typeof Workspaces.$inferSelect;
export type NewWorkspace = typeof Workspaces.$inferInsert;
```

Table TS only. Migration generate/apply: `AGENTS.md`.

## Interface

Drop the entity noun. Persistence verbs — not domain `create` / `getById`.

| Method | Meaning |
| ------ | ------- |
| `save` | insert |
| `update` | patch; return row or `null` |
| `findById` / `findByIds` / `findMany` | read; **null / empty**, never throw not-found |
| `existsBy…` | boolean existence |
| `softDelete` / `hardDelete` | delete |

```ts
export type WorkspaceRepositoryOptions = { tx: DbClient };

export interface IWorkspaceRepository {
  save: (
    entity: CreateWorkspaceEntity,
    options?: WorkspaceRepositoryOptions,
  ) => Promise<Workspace>;
  update: (
    id: string,
    entity: UpdateWorkspaceEntity,
    options?: WorkspaceRepositoryOptions,
  ) => Promise<Workspace | null>;
  findById: (id: string) => Promise<Workspace | null>;
  findByIds: (ids: string[]) => Promise<Workspace[]>;
  findMany: (filter: ListWorkspacesFilter) => Promise<Workspace[]>;
  existsBySlugInTenant: (tenantId: string, slug: string) => Promise<boolean>;
  softDelete: (id: string, options?: WorkspaceRepositoryOptions) => Promise<boolean>;
}
```

Qualify filters (`existsBySlugInTenant`), not the type name (`findWorkspaceById`).

## Recipe

- `@injectable()` class; inject `TYPES.Database`
- `private client(options?) { return options?.tx ?? this.db; }` for transactional writes
- `uuidv7()` for new ids; bump `version` on update/softDelete
- Filter soft-deleted rows with `isNull(table.deletedAt)` unless the method is about deleted rows
- No authz, events, or not-found errors — `service`

```ts
@injectable()
export class WorkspaceRepository implements IWorkspaceRepository {
  constructor(@inject(TYPES.Database) private readonly db: Database) {}

  async save(
    entity: CreateWorkspaceEntity,
    options?: WorkspaceRepositoryOptions,
  ): Promise<Workspace> {
    const client = this.client(options);
    const [created] = await client
      .insert(Workspaces)
      .values({
        id: uuidv7(),
        tenantId: entity.tenantId,
        name: entity.name,
        slug: entity.slug,
        createdAt: new Date(),
        version: 1,
      })
      .returning();
    return created;
  }

  private client(options?: WorkspaceRepositoryOptions) {
    return options?.tx ?? this.db;
  }
}
```

```ts
TYPES.WorkspaceRepository = Symbol.for("IWorkspaceRepository");
container.bind<IWorkspaceRepository>(TYPES.WorkspaceRepository).to(WorkspaceRepository);
```

Export interface + impl from the repositories barrel.

## Anti-patterns

- Throwing not-found from the repository
- `create` / `getById` as repository method names
- Authz or CloudEvent publish here
- Hand-writing or auto-running migrations

## Done when

- Table exported from `schema.ts` when persistence changes
- `I*Repository` + impl + TYPES + bind
- Reads return null/empty; migrations not generated by the agent
